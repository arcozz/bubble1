# Tab Open Animations for Zen

Une animation bien visible à chaque **ouverture d'onglet** (clic milieu sur un lien, Ctrl+T, etc.).
Les effets sont dessinés par-dessus la fenêtre : ils peuvent dépasser de la sidebar.

## Styles (réglage « Animation Style »)

| Style | Rendu |
|---|---|
| Explosion (défaut) | l'onglet gonfle d'un coup, ondes de choc et éclats autour |
| Aimant | des particules sont aspirées vers l'emplacement, puis l'onglet « pop » |
| Vol depuis la droite | un double de l'onglet traverse la fenêtre et atterrit dans la sidebar |
| Aléatoire | un style différent à chaque ouverture |

- Réglage **Speed (%)** : 100 = normal, 50 = deux fois plus lent, 200 = deux fois plus rapide.
- Les onglets restaurés au démarrage ne sont pas animés.
- Si rien ne s'affiche : active **Debug**, ouvre la Console (Ctrl+Shift+J) et ouvre un onglet.
